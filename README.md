# Mitia

میتیا برنامه‌‌ی سبک ویندوزی برای کاهش حجم تصاویر و ویدئوهاست. می‌توانید کیفیت و ابعاد فایل‌ها را تنظیم کنید، فرمت تصاویر را تغییر دهید و چند فایل را هم‌زمان فشرده کنید. برنامه از فارسی و انگلیسی پشتیبانی می‌کند و فایل‌های اصلی را دست‌نخورده نگه می‌دارد.

Mitia is a lightweight Windows app for reducing the file size of images and videos. You can adjust file quality and dimensions, convert image formats, and compress multiple files at once. The app supports Persian and English and keeps your original files unchanged.
